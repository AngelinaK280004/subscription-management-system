# subscription-management-system
Business analysis case: Subscription management personal cabinet <br>
Личный кабинет управления подписками (Business Analysis Case)

## О проекте
Учебный кейс по проектированию личного кабинета для SaaS-сервиса. <br>
Цель: разработать концепцию ЛК, описать бизнес-процессы, спроектировать API и подготовить ТЗ.<br>

## Стек и инструменты
Нотации: BPMN 2.0, UML (Class, Sequence)<br>
Инструменты: Miro, Swagger, Postman, Excel<br>
Методологии: Agile, User Stories (INVEST)<br>

## Структура репозитория
01_Stakeholders — Анализ стейкхолдеров, матрица влияние/интерес.<br>
02_Requirements — User Stories, Use Cases, критерии приемки.<br>
03_BPMN_Processes — Модели процессов as-is и to-be (смена тарифа, отключение).<br>
04_UML_Diagrams — Диаграммы классов и последовательностей.<br>
05_API_and_Testing — Спецификация OpenAPI (Swagger) и коллекция Postman для тестирования.<br>
06_Documentation — Итоговое техническое задание (ТЗ).

## Результаты
Сформирован полный пакет проектной документации, готовый к передаче в команду разработки. Спроектированный API протестирован на позитивные и негативные кейсы.
