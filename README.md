# subscription-management-system
Business analysis case: Subscription management personal cabinet 
Личный кабинет управления подписками (Business Analysis Case)

## О проекте
Учебный кейс по проектированию личного кабинета для SaaS-сервиса. 
Цель: разработать концепцию ЛК, описать бизнес-процессы, спроектировать API и подготовить ТЗ.

## Стек и инструменты
Нотации: BPMN 2.0, UML (Class, Sequence)
Инструменты: Miro, Swagger, Postman, Excel
Методологии: Agile, User Stories (INVEST)

## Структура репозитория
'01_Stakeholders' — Анализ стейкхолдеров, матрица влияние/интерес.
02_Requirements — User Stories, Use Cases, критерии приемки.
03_BPMN_Processes — Модели процессов as-is и to-be (смена тарифа, отключение).
04_UML_Diagrams — Диаграммы классов и последовательностей.
05_API_and_Testing — Спецификация OpenAPI (Swagger) и коллекция Postman для тестирования.
06_Documentation — Итоговое техническое задание (ТЗ).

## Результаты
Сформирован полный пакет проектной документации, готовый к передаче в команду разработки. Спроектированный API протестирован на позитивные и негативные кейсы.
